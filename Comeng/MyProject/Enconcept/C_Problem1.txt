1. เขียนโปรแกรมวน loop รับค่าจาก Keyboard เป็นตัวเลขจำนวนเต็มบวกไปเรื่อยๆ จนกระทั่งได้รับเลข 0 จาก keyboard จากนั้น ให้ออกจาก loop แล้วหาค่าแฉลี่ยของตัวเลขจำนวนเต็มบวกทั้งหมด และแสดงผลลัพธ์แค่ค่าเฉลี่ยเท่านั้นออกมาบน console
เช่น ค่าเฉลี่ย = ผลบวกของตัวเลขทั้งหมด/จำนวนตัวเลขทั้งหมด = (7 + 5 + 4 + 5 + 3)/5 = 4.8 // ให้แสดงผลลัพธ์แค่ 4.8 ออกทางหน้าจอ


2. เขียนโปรแกรมแปลงค่าเงิน THB ไปเป็นเงิน USD หรือ EUR หรือ JPY โดยสามารถรับ input จาก keyboard เป็นเลขที่มีทศนิยมที่มีค่ามากกว่า 0 ขี้นไป และให้ user เลือกว่า จะแปลงเงินบาทเป็นสกุลเงินใดใน 3 สกุลเงินที่กำหนด พร้อมคำนวณค่าเงินของสกุลเงินเหล่านั้นจากการแปลงค่าเงินบาทออกมาด้วย
กำหนดให้ Exchange Rate: 1 USD = 33.38 THB, 1 EUR = 38.43 THB, 1 JPY = 0.2126 THB

3. จาก code ด้านล่างนี้ (ห้ามรัน code กับ compiler นะคะ ให้ลองไล่ code ด้วยตัวเอง สามารถทดเลยในกระดาษได้ค่ะ)
#include <stdio.h>
int main ()
{
        int i, j;
        int a [8] = {1, 2, 3, 4, 5, 6, 7, 8};
        for(i = 0; i < 3; i++) {
             a[i] = a[i] + 1;
             i++;
        }
        i--;
        for (j = 7; j > 4; j--) {
              int i = j/2;
              a[i] = a[i] - 1;
        }
        printf ("%d, %d", i, a[i]);
}
